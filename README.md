# if love · 主题美化器

酒馆（SillyTavern）扩展。用来管理主题、自动切换主题，并对任何主题做一层通用修正。

## 安装

在酒馆「扩展」→「安装扩展」中粘贴仓库地址：

```text
https://github.com/ruoege49-ship-it/love-theme-manager
```

也可以把整个 `love-theme-manager` 文件夹放到：

```
SillyTavern/public/scripts/extensions/third-party/
```

重启酒馆或刷新页面后，在「扩展」面板里找到「if love · 主题美化器」。

## 功能

- **主题**：导入酒馆主题 JSON 或单独的 .css 文件，一键切换，可以撤销上一次切换。每个主题能写简介、设分组、设占位句、换封面，还能**绑定背景图**：一个主题可以绑一张或多张，切过去时用主背景或随机一张，撤销时背景也换回去。
- **自动**：日夜切换（白天、夜晚各一个主题）；按十二时辰切换；按角色卡切换；随机主题（每天一个 / 每次进来）；从背景图取色。
- **修正**（五组，每项单独开关）：聊天楼层、输入区、面板与弹窗、预设列表、显示与性能。
- **字体**：正文字体、名字字体（含英文花体），字号、行距、字距、段距。可以**上传自己的字体文件**（ttf / otf / woff / woff2，存在酒馆服务器上），自定义链接支持 CSS 链接、字体文件链接和 Google Fonts 网页链接。
- **头像**：角色和自己分开设置布局（含三种大头像：卡片顶图、居中半身、左侧立绘）、形状、大小；大头像自动用原图。
- **魔棒快捷调整**：输入框左边的魔棒菜单里有「if love · 快捷调整」，可以随机换主题、撤销切换、开关日夜，快速调正文字号、行距、字距、段距和字体。
- **检查当前页面**：找出楼层超宽、正文不居中、头像拉伸、禁用条目变灰、默认渐变标题条等问题，一键开启对应的修正。

面板和快捷弹窗的颜色跟随当前主题。所有字体和头像选项默认「跟随主题」，只有改过的那一项才会覆盖主题。

> 扩展版和酒馆助手脚本版用的是同一份设置，二选一安装，不要同时开。

## 给主题作者：在 JSON 里写简介

在主题 JSON 里加下面几个字段（`love_bg` 是酒馆背景库里的文件名，多张写成数组；`love_bg_mode` 填 `main` 或 `random`），导入时会自动读取（酒馆本身会忽略它们）：

```json
{
  "name": "十二时辰·子·孤独",
  "love_desc": "黑底夜窗，窄正文，夜蝶。",
  "love_series": "十二时辰",
  "love_placeholder": "夜很长，慢慢写。",
  "love_bg": "背景文件名.jpg"
}
```

## 内置主题

在 `themes.js` 的 `BUILTIN_THEMES` 里按注释的格式添加。

## 说明

- 修正层的样式写在 `<style id="love-tm-layer">` 里，排在主题的自定义 CSS 后面，使用酒馆官方的选择器和变量。只在需要压过内联样式或主题里的 `!important` 时才用 `!important`。
- 霞鹜文楷从 jsDelivr 加载，思源宋体、思源黑体和站酷小薇从 Google Fonts 加载。加载不了的话，可以用「自定义」填别的字体链接。
